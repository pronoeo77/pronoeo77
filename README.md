# 01 | CommissionOS

### Sales Compensation Analytics & Commission Simulation

**Business Focus: Sales Operations & Financial Modeling**

CommissionOS is an interactive financial analytics application designed to demonstrate how organizations can calculate sales commissions, evaluate compensation structures, and identify revenue attribution issues.

Rather than simply displaying financial results, the application allows users to **simulate changes to commission plans and immediately see their financial impact**.

**Key Capabilities**

- **Commission Calculations:** Models compensation across 80 fictional employees, including Account Executives, Account Managers, and Management.
- **Scenario Simulation:** Allows users to adjust compensation assumptions and compare financial outcomes.
- **Revenue Integrity:** Identifies attribution exceptions and potential commission exposure.
- **Compensation Logic:** Demonstrates tiered commissions, accelerators, ramp guarantees, and retention incentives.
- **Management Reporting:** Provides executive-level metrics and hierarchical commission rollups.

**Technologies:** React, TypeScript, JavaScript, Vite, Recharts, CSS, GitHub Actions

# 02 | RCM Intelligence

### Healthcare Revenue Cycle Analytics & Performance Monitoring

**Business Focus: Healthcare Finance & Revenue Cycle Management**

RCM Intelligence is an interactive financial analytics dashboard designed to help healthcare organizations examine revenue performance, understand payer-related trends, and identify potential operational inefficiencies.

Unlike CommissionOS, which emphasizes compensation calculations and scenario modeling, RCM Intelligence focuses on **monitoring financial performance, investigating revenue discrepancies, and making complex healthcare financial metrics easier to interpret**.

**Key Capabilities**

- **Financial Performance:** Presents executive-level revenue cycle metrics and operational KPIs.
- **Revenue Reconciliation:** Helps users examine financial differences and investigate discrepancies.
- **Denial Analysis:** Visualizes denial trends and patterns affecting revenue cycle performance.
- **Payer Comparisons:** Supports analysis of financial performance across different payers.
- **Metric Transparency:** Provides clearly defined financial measures to support consistent interpretation.

**Technologies:** React, JavaScript, Recharts, CSS, GitHub Actions
