### CommissionOS

**Interactive Sales Compensation Analytics & Commission Simulation Dashboard**

An interactive application demonstrating sales compensation analytics, revenue integrity analysis, automated commission calculations, and compensation scenario modeling.

The dashboard includes five analytical modules: Executive Overview, Commission Explorer, Revenue Integrity, Compensation Simulator, and Commission Logic.

**Key Capabilities:**
- Model compensation across 80 fictional employees, including Account Executives, Account Managers, and Management.
- Calculate tiered commissions, accelerator rates, ramp guarantees, and retention incentives.
- Simulate compensation plan changes using interactive controls with real-time financial impact calculations.
- Analyze revenue attribution exceptions and potential commission exposure.
- Validate management revenue rollups and commission calculations using deterministic synthetic data.

**Technologies:** React, TypeScript, JavaScript, Vite, Recharts, CSS, GitHub Actions
